Présentation de Grade Tracker

Grade Tracker est une application console Java permettant de suivre les notes et moyennes de plusieurs étudiants simultanément.


Pourquoi cette application ?

Cette application avait comme but de me familiariser avec le langage Java de façon ludique.


Comment ça marche ?

Au démarrage de l'application, l'utilisateur pourra choisir l'action a réalisé.

Ce dernier peut naviguer dans les différents menus en rentrant le numéro associé au menu dans la console.


S'il souhaite saisir une note, il devra ensuite choisir l'élève concerné.

Ensuite, l'utilisateur devra choisir la matière concerné.



Après cela, il devra choisir la note à ajouter.


L'utilisateur à aussi la possibilité de consulter les notes de tous les étudiants simultanément.


Enfin, l'utilisateur peut consulter la moyenne des élèves.
