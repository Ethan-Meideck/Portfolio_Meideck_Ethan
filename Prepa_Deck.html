Présentation de PrepaDeck

PrepaDeck est une application de bureau Windows permettant aux techniciens de Xefi Chelles de gagner du temps lors de la préparation des postes clients.


Pourquoi cette application ?

Avec notre métier de Technicien Conseil, nous sommes très régulièrement confronté à préparer de nombreux postes pour nos clients, parfois par dizaine. Nonobstant, si nous préparons des postes, nous ne pouvons pas allouer ce temps pour résoudre les problèmes bloquants de nos clients.

PrepaDeck répond donc à cette problématique en permettant d'automatiser une très grande partie de la préparation d'un poste Windows.

L'application fonctionne avec une logique "Fire and Forget" ce qui signifie qu'une fois lancé, le technicien peut travailler sur d'autres tâches le temps que le poste se prépare.


Comment ça marche ?

Pour commencer, le technicien doit choisir les options devant s'exécuter. Chaque option est représenté par une case à cocher. Vous pouvez retrouver l'interface de l'application ci dessous.


Après la sélection réalisé, le technicien doit cliquer sur "Démarrer la sélection".

Si la case "Renommer l'ordinateur" a été coché, l'application demandera le nom à mettre pour l'ordinateur.



Ensuite, les scripts seront exécuté dans un ordre bien précis. Cette séquence permet d'éviter certaines tâches inutiles et de gagner du temps.

Par exemple, il est inutile de mettre à jour une application qui sera désinstallé quelques minutes plus tard.


Une fois que tous les scripts sont exécutés, une fenêtre apparaitra pour notifier le technicien.
